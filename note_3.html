Subject: Numbers in the Underground Structure

Prerequisite: Read through Book 1 before opening these notes.

Inscription Fonts

Throughout the underground structure are large inscriptions on the walls. They can be engraved in stone, stamped in metal or painted on tile. These inscriptions are made up of no more than seven symbols each. These symbols represent the numbers zero through six.

These inscriptions can be decoded into pictographic hints about structure control codes using the numerical values for the symbols and their patterns.

Although each inscription only has no more than seven symbols in it, there are more than seven symbols across multiple inscriptions. Seven fonts have been identified. They are listed here in the order of increasing complexity of the inscriptions they were discovered in.

Higher Values

Numbers higher than six are written with a combination of the existing symbols. Reading left to right, if the next digit is the same or larger the two numbers are multiplied. If the number is smaller, that number is added. Each increasing and decreasing set of numbers is a chunk. Each chunk is computed first before multiplication or addition is done between chunks. Multiplication is done first, with the addition second. A zero forces the switch from multiplication to addition and ends the chunk.

FIELD NOTE HIGHER NUMBERS :
There are alternates for writing higher value numbers that are also valid. 26 can be writen as 606. The above table gives the most common version of each number. Current theory is that this base six, Roman style number system is used in the structure as a form of obfuscation.
